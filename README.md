framework name : HHT.js

Use a progressive API design:
simple and readable syntax for beginners,
with lower-level APIs for advanced users who need more control.

```
mini-framework/
│
├── package.json
├── README.md
├── index.html
│
├── framework/
│   ├── index.js
│   ├── dom.js
│   ├── store.js
│   ├── router.js
│   ├── events.js
│   └── app.js
│
├── todo/
│   ├── app.js
│   ├── actions.js
│   ├── components/
│   └── styles.css
│
└── docs/
    └── documentation.md
```

HHT.js will use direct event listeners.
